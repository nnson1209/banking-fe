# Shark Bank - Banking Frontend

## Project Overview
Shark Bank is a modern banking frontend built with React. The app provides a clean customer and auditor experience for managing accounts, viewing transactions, making transfers, and handling profile/authentication flows.

## Features
- Authentication: login, register, forgot password, reset password
- Customer profile page with personal information, account summary, and recent transactions
- Change password flow
- Account transfer flow with destination account verification
- Transaction history with pagination and account selection
- Auditor dashboard for searching users, accounts, and transactions
- Deposit flow for auditor/admin users
- Role-based routing and protected pages
- Responsive dark-slate UI with modern navbar and page layouts
